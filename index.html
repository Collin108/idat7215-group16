2 人 / 2 members

数据与复现组Data & reproduction

任务 / Tasks
整理 AMdataset 标注，固定训练、验证和测试划分。独立按 README 重跑实验与绘图。Check AMdataset labels and fix the train, validation and test splits. Follow the README to rerun experiments and plots.

交付 / Outputs
数据划分清单、预处理脚本、可复现性检查记录及 README。Split manifest, preprocessing script, reproduction check and README.

2 人 / 2 members

模型实验组Model experiments

任务 / Tasks
用 Python 微调预训练模型，复现选定论文结果。比较基线与另一组模型或参数，解释结果差异。Fine-tune a pretrained model in Python to reproduce selected paper results. Compare a baseline with another model or setting and explain differences.

交付 / Outputs
训练与评估源码、运行配置、指标对照表及可绘图的实验结果。标明开源复用与自编代码。Training and evaluation code, run settings, metrics table and plot-ready results. Identify reused and original code.

2 人 / 2 members

报告与图表组Report & figures

任务 / Tasks
用实验数据制作图表，撰写引言、项目描述、结果与讨论、结论。收齐个人贡献说明，统一 IEEE 引用和排版。Turn experiment data into figures. Write the introduction, project description, results and discussion, and conclusion. Collect contributions and standardize IEEE citations and formatting.

交付 / Outputs
书面报告终稿、带图注的图表。正文 2,000–4,000 词，A4、单倍行距、12 磅 Times New Roman。Final written report and captioned figures. 2,000–4,000 words, A4, single spacing, 12 pt Times New Roman.

1 人 / 1 member

汇报材料组Presentation materials

任务 / Tasks
把方法和关键结果做成幻灯片，安排讲解与彩排，准备常见问答。Build slides around the method and key results. Assign speaking parts, rehearse and prepare for questions.

交付 / Outputs
汇报演示文件、讲解分配与问答提纲。全员到场：汇报 15 分钟，问答 5 分钟。Slide deck, speaking plan and Q&A notes. All members attend: 15 minutes presenting and 5 minutes for questions.
